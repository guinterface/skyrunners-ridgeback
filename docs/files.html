Sheets, code and CAD

Everything behind the numbers on this site. The sheets and pages are rebuilt from two plain files, so a change made there is permanent and shows up everywhere.

Change a value or a link

Easiest: press Edit at the top right of any page. Type your name and the team passcode (ask in the club Slack; no GitHub account needed). Then click the ✎ next to any number, text, shop link or paper (or double-click it), change it and press Save: in the part panel and parts table on the drone page, and in the design numbers on the calculations page. "Edit all fields at once" opens the whole part as a form. Each save is a commit with your name, the site updates in about two minutes, and Recent edits below has an Undo button (how the passcode relay works). Or edit the files directly:

  1. Open the file (link above) and sign in to GitHub. Each line says what the number is and where it comes from.
  2. Change the value and press Commit changes. That saves it for good, with your name and the date in the history.
  3. About 2 minutes later the six sheets, every calculation and these pages are rebuilt from it. Progress: Actions. If a value breaks a formula or a name is mistyped, the rebuild stops, the site keeps the old version and the Actions page says why.

Saving needs write access to the repository (ask a lead); anyone else can propose the change and a lead accepts it. Edits made inside the Google Sheets copies are not kept: the next rebuild replaces them. Numbers in the long tables (drag of each part, the motor maker's test table, connector ratings) are still in sheets/build_sheet.py.

Where the part models come from

Each bought part on the drone page is its own model in docs/assets/models. Models marked "official CAD" are the maker's own published file (T-Motor, Holybro, CubePilot and Pololu publish theirs with no licence text; Raspberry Pi and Adafruit files are MIT); the rest we drew from the maker's drawing or photos (CC0). Size and source of every one: data/model_sources.json.
